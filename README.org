* cuik.vim

A dead simple plugin to run any program or script inside (Neo)Vim and
send its output to the quickfix list.

Works on Vim 8.1.1418+ and Neovim 0.5+.

** Why "cuik"?

It's a funny name!

** Whats is cuik?

This plugin is an "extension" to the default =:make= cmd in vim, it allows the user run any cmd and get the output on the quickfix list, making it works like like the compile mode from emacs(where i get the inpiration)

*See* [[*Usage][Usage]]

** Install

*** vim-plug

#+BEGIN_SRC vim
Plug 'offGustavo/cuik.vim'
#+END_SRC

*** lazy.nvim

#+BEGIN_SRC lua
return { 'offGustavo/cuik.vim' }
#+END_SRC

With custom options (=init= runs before the plugin loads):

#+BEGIN_SRC lua
return {
  'offGustavo/cuik.vim',
  init = function()
    vim.g.cuik = {
      run_async = true,
    }
  end,
}
#+END_SRC

*** vim.pack (Neovim 0.12+)

Set your options before =vim.pack.add=, since it loads the plugin right away.

#+BEGIN_SRC lua
vim.g.cuik = {
  run_async = true,
}

vim.pack.add({ 'https://github.com/offGustavo/cuik.vim' })
#+END_SRC

*** Native packages

#+BEGIN_SRC sh
# Vim
git clone https://github.com/offGustavo/cuik.vim \
  ~/.vim/pack/plugins/start/cuik.vim

# Neovim
git clone https://github.com/offGustavo/cuik.vim \
  ~/.local/share/nvim/site/pack/plugins/start/cuik.vim
#+END_SRC

*** Manual

Copy =plugin/cuik.vim= and =autoload/cuik.vim= into your own config
directory (=~/.vim= or =~/.config/nvim=).

** Usage
END:

| Command             | Short            | Really Short | Description                                    |
|---------------------+------------------+--------------+------------------------------------------------|
| =:CuikCompile=      | =:CCompile=      | =:CC=        | Run a command (follows the =run_async= option) |
| =:CuikCompileAsync= | =:CCompileAsync= | =:CA=        | Run a command without blocking the editor      |
| =:CuikCompileSync=  | =:CCompileSync=  | =:CS=        | Run a command and wait until it finishes       |
| =:CuikRecompile=    | =:CRecompile=    | =:CR=        | Run the last command again                     |
| =:CuikKill=         | =:CKill=         | =:CK=        | Stop the running command                       |

Pass the command as an argument, or leave it out to get a prompt:

#+BEGIN_SRC vim
:CuikCompile make -j4<Cr> " Will execute the command
:CuikCompile<Cr> " Will ask the user for a command to run
#+END_SRC

The short names are only defined when =short_cuik_cmds= is enabled.

** Config

Set =let g:cuik= or =vim.g.ciuk= *before* the plugin loads. Any missing key uses its default.

| Option              | Default | Description                                                                      |
|---------------------+---------+----------------------------------------------------------------------------------|
| =default_cmd=       | =''=    | Command pre-filled in the prompt, use =b:cuik_cmd= to set a buffer local command |
| =run_async=         | false   | Don't block the editor while the command runs                                    |
| =open_qf=           | true    | Open the quickfix window when a command starts                                   |
| =auto_scroll=       | true    | Keep the quickfix window on the newest line                                      |
| =prompt=            | ='$ '=  | Prompt shown when asking for a command                                           |
| =short_cmds=        | false   | Define =CCompile=, =CAsync=, =CSync=, =CRecompile= and =CKill=                   |
| =really_short_cmds= | false   | Also define =CC=, =CA=, =CS=, =CR= and =CK=                                      |

*** Vimscript

#+BEGIN_SRC vim
let g:cuik = {
            \ 'default_cmd': '',
            \ 'run_async': v:false,
            \ 'open_qf': v:true,
            \ 'auto_scroll': v:true,
            \ 'prompt': '$ ',
            \ 'short_cmds': v:false,
            \ 'really_short_cmds': v:false,
            \ }
#+END_SRC

*** Lua

#+BEGIN_SRC lua
vim.g.cuik = {
  default_cmd     = '',
  run_async       = false,
  open_qf         = true,
  auto_scroll     = true,
  prompt          = '$ ',
  short_cmds = false,
  really_short_cmds = false,
}
#+END_SRC
